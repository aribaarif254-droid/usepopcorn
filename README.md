# 🍿 UsePopcorn

UsePopcorn is a movie search and rating application built with **React and JavaScript**. The application uses a **movie API** to fetch movie data and allows users to search for movies, view movie details, rate movies, and keep track of watched movies.

## ✨ Features

* 🔎 Search for movies
* 🎬 View detailed movie information
* ⭐ Rate movies
* 📋 Save and manage watched movies
* 🌐 Fetch movie data using an API
* ⚛️ Built with React
* 💻 Developed using JavaScript

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML
* CSS
* Movie API
* API Integration

## 🚀 Getting Started

To run the project locally, first clone the repository:

```bash
git clone https://github.com/aribaarif254-droid/usepopcorn.git
```

Then move into the project folder:

```bash
cd usepopcorn
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will then run locally at:

```text
http://localhost:3000
```
